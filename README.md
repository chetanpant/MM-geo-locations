# WhatsApp Chatbot Geo Location Visualization

This project is a simple geospatial visualization created to understand where users of a WhatsApp chatbot were located.

The purpose was to help the program team get a quick view of user spread across different locations and understand the reach of the chatbot.

## What this project shows

- User locations plotted on a map
- Geographic spread of chatbot users
- A simple visual layer for program monitoring and engagement analysis

## Context

WhatsApp chatbots are often used by nonprofit and program teams to reach users at scale. Once users start engaging with the bot, it becomes useful to understand where they are coming from and how widely the program is spreading.

This project was created as a lightweight way to visualize that location data.
